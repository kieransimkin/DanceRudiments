# DanceRudiments authors and music

Created by **Kieran Simkin** as part of the **DanceFlow** BPM and motion-response workflow.

**Music, artwork and real-world uses: [Kieran Simkin — My Songs](https://kieransimkin.co.uk/my-songs/)**

Source and issue tracker: https://github.com/kieransimkin/DanceRudiments

DanceRudiments supplies deterministic C++ movement functions with Python and
TypeScript/JavaScript bindings. StemLab supplies musical timing evidence;
DanceMoves applies timed motion to WordPress pages. The components can be used
independently. Attribution for imported source data remains in the original
third-party notices; this author link does not replace those credits or licences.
